# Project Overview

This project focuses on customer intelligence, business growth analytics, and customer retention analysis using Python and Tableau. The project analyzes e-commerce customer behavior data to generate actionable business insights through data analytics and interactive dashboards.

The project combines:

* Data preprocessing and analysis using Python
* Exploratory Data Analysis (EDA)
* Business intelligence reporting
* Interactive Tableau dashboards
* Customer retention and growth analysis

---

# Objectives

* Analyze customer purchasing behavior
* Identify customer retention patterns
* Understand revenue and sales trends
* Generate business insights for decision-making
* Build interactive dashboards for visualization
